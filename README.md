# 🛍️ Real-Time Price Intelligence & Deal Recommendation System

Live portfolio project featuring multi-factor deal scoring (30% Discount, 25% Savings, 25% Rating, 20% Popularity), interactive filtering, and visual analytics.

## 🚀 Two Ways to Host Permanently
1. **GitHub Pages (Instant, Never Sleeps):** Upload `index.html` to your GitHub repo and enable **Settings -> Pages**.
2. **Streamlit Community Cloud:** Connect this GitHub repository at `share.streamlit.io` and select `app.py`.
